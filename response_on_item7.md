**The caveat on "one-line swap in the same spot."** P2's `(k+SNR)^(−γ)` is published as a multiplier on the **ε-loss**, not the x0-loss. To run *actual* P2 on an x0-predictor, the multiplier on your x0-MSE has to be

```
w_x0(t) = SNR(t) · (k + SNR(t))^(−γ)

The general rule, which sidesteps all of this: to realize any desired ε-currency weight `w̃(σ)` from an x0-predictor, set the x0-loss multiplier to `SNR·w̃`.
